# Nature Figure Learner

An installable, standalone agent skill for extracting reusable scientific
figure patterns from paper figures and plotting code. Markdown plus YAML
frontmatter is the durable source of truth; `index.json` is derived.

## What It Provides

- Figure and plotting-code analysis workflows with scientific context retained
  for the agent.
- Strict `FigurePattern` schema validation and Markdown persistence.
- Deterministic query, mock-data, renderer, and objective image-validation
  helpers.
- Optional bridge use with `nature-figure`.

The LLM owns `scientific_claim`, `hero_panel`, `evidence_hierarchy`, and the
optional `ScientificReview`. Python owns schema, path safety, duplicate checks,
persistence, query ranking, synthetic data, rendering, and objective checks.

## Install-Free Commands

The launcher works directly from a source checkout and emits one JSON Envelope
on stdout:

```bash
python scripts/figure_kb.py schema export
python scripts/figure_kb.py pattern validate --input pattern.json
python scripts/figure_kb.py pattern save --input pattern.json --narrative narrative.md
python scripts/figure_kb.py query --chart-type grouped-bar --limit 5
python scripts/figure_kb.py self-validate --pattern-id pattern-001 --output-dir previews
python scripts/figure_kb.py index audit
python scripts/figure_kb.py index rebuild
```

Progress and debug output use stderr. `unsupported` is a capability result and
exits 0; command errors return a non-zero status. See `INSTALL.md` and
`references/query-templates.md` for details.

The initial renderer adapters support grouped/stacked/horizontal bars,
line-trend/multi-line, scatter/bubble, heatmap, violin, and box. Other chart
types remain valid schema records but report `unsupported` during rendering.

Normal skill workflows do not run tests. The test suite is reserved for
development and release verification.

## First Invocation Gate

Before any KB read/write workflow, run:

```bash
python scripts/kb_location_manager.py --get-path
```

If it returns `NOT_CONFIGURED`, ask the user to choose a location and run the
setup flow. Keep real KB data outside this repository.

## Public Repository Safety

Do not commit real KB data, paper PDFs or screenshots, private paths, images,
credentials, tokens, or generated bytecode. Synthetic fixtures belong only in
tests.

## Verification

```bash
python -B -m unittest discover -s tests -t . -v
python -B -m unittest scripts.test_self_evolution_engine -v
python -B -m py_compile scripts/figure_kb.py scripts/kb_location_manager.py scripts/self_evolution_engine.py
```

The four validation levels and workflow boundaries are described in the design
specification under `docs/superpowers/`.
