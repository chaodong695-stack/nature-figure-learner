# Contributing

Keep contributions focused on the documented skill and its deterministic
helpers. Preserve the distinction between LLM scientific judgment and Python
mechanics.

## Ground Rules

- Do not add real KB data, paper PDFs, copyrighted screenshots, private paths,
  credentials, or tokens.
- Keep user KB data outside the repository.
- Use the existing schema, Repository, query, renderer, and validation APIs.
- Add a failing test before implementing a new behavior.
- Keep `SKILL.md` trigger-focused and link to references instead of duplicating
  executable logic.

## Verification

```bash
python -B -m unittest discover -s tests -t . -v
python -B -m unittest scripts.test_self_evolution_engine -v
python -B -m py_compile scripts/figure_kb.py scripts/kb_location_manager.py scripts/self_evolution_engine.py
git diff --check
```

Review the working tree for generated bytecode or private material before a
change is published.
